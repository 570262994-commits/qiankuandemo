# 双看板路由模式重构实施计划

## 一、整体架构设计

### 1. 新增状态管理

* 创建 `src/store/viewModeStore.ts`

* 定义 `ViewMode` 类型：`'collection' | 'journal'`

* 存储当前视图模式状态

### 2. 页面结构重构

* 保留 `Dashboard.tsx` 作为账目模式页面

* 新建 `Collection.tsx` 作为催收模式页面

* 或者在 Dashboard 内部通过 viewMode 切换显示内容

## 二、详细实施步骤

### 阶段一：状态层改造

**1. 创建 viewModeStore.ts**

```typescript
type ViewMode = 'collection' | 'journal';
// collection: 催收模式
// journal: 账目模式
```

**2. 修改 App.tsx**

* 引入 viewModeStore

* 顶部添加双看板切换 Tab

### 阶段二：UI 层重构

**1. 顶部切换区设计**

* 左侧：催收模式 Tab（红/橙色）

  * 图标 + "异常提醒"

  * 角标显示需关注客户数

* 右侧：账目模式 Tab（蓝/绿色）

  * 图标 + "财务流水"

  * 角标显示今日录入笔数

**2. 中间统计区**

* 催收模式：总待收金额 + 逾期总额

* 账目模式：还款清单 + 欠款清单

**3. 底部列表区**

* 催收模式：按逾期天数排序的客户卡片

* 账目模式：按时间排序的交易流水

### 阶段三：筛选器联动

**1. 催收模式筛选器**

* 客户搜索

* 逾期深度筛选（1周内/1个月内/1个月以上）

**2. 账目模式筛选器**

* 交易日期选择

* 欠款/还款类型切换

### 阶段四：视觉优化

**1. 主题色适配**

* 催收模式：淡红色背景、警告图标

* 账目模式：深蓝色背景、专业风格

**2. 卡片样式**

* 催收卡片：突出逾期天数、红色警示

* 账目卡片：突出交易类型、金额

## 三、涉及文件

| 文件                                  | 操作     | 说明          |
| ----------------------------------- | ------ | ----------- |
| `src/store/viewModeStore.ts`        | 新建     | 视图模式状态管理    |
| `src/App.tsx`                       | 修改     | 添加顶部切换 Tab  |
| `src/pages/Dashboard.tsx`           | 重构     | 支持双看板模式     |
| `src/pages/Collection.tsx`          | 新建（可选） | 催收模式独立页面    |
| `src/components/ViewModeTab.tsx`    | 新建     | 顶部切换组件      |
| `src/components/CollectionCard.tsx` | 新建     | 催收模式客户卡片    |
| `src/components/FilterDrawer.tsx`   | 修改     | 根据模式显示不同筛选项 |

## 四、数据查询逻辑

**催收模式查询**

* 筛选有欠款且已逾期/即将到期的客户

* 按逾期天数降序排列

**账目模式查询**

* 显示所有交易流水

* 按时间降序排列

## 五、预期效果

1. 用户可快速在"催收"和"账目"两种视角间切换
2. 筛选逻辑不再冲突，每种模式有独立的筛选条件
3. 视觉上区分明显，催收模式有警示感，账目模式专业简洁
4. 修复卡片中的 NaN% 错误

## 六、实施顺序

1. 创建 viewModeStore
2. 修改 App.tsx 添加顶部切换
3. 重构 Dashboard.tsx 支持双模式
4. 实现筛选器联动
5. 视觉优化和测试
