## 问题分析与修复计划

### 问题 1：客户管理页固定账期显示错误
**现象**：固定账期显示为"0 天"或"铃铛 0 天"

**原因**：
- 当前逻辑在判断时，当 `daysUntilDue <= 3` 时显示剩余天数，但固定账期本身应该是设置的固定值（如30天）
- 应该始终显示设置的固定账期值，只在旁边根据剩余天数显示提醒图标

**修复方案**：
- 固定账期始终显示设置的值（如"30 天"）
- 当剩余天数 ≤ 3 且未逾期时，在数值旁显示铃铛图标
- 已逾期时，显示"已逾期 N 天"替代固定账期值
- 未设置账期时，显示"未设置"

### 问题 2：首页筛选器点击无反应
**现象**：点击"已逾期"、"7天内到期"筛选按钮没有过滤效果

**原因**：
- 当前只计算了 `filteredCustomers` 但没有在 UI 中使用
- 筛选器状态改变后没有实际过滤交易列表

**修复方案**：
- 将客户筛选逻辑应用到交易列表过滤
- 当选择筛选条件时，只显示符合条件的客户的交易记录
