## 信用额度系统优化计划（增强版）

### 1. 类型定义 (`src/types/index.ts`)
- `creditLimit` 类型改为 `number | null`
- `null` 表示无限额度

### 2. Supabase API (`src/lib/supabaseApi.ts`)
- 更新映射函数处理 `null` 值

### 3. 添加客户对话框 (`src/components/AddCustomerDialog.tsx`)
- 默认信用额度为"无限"（null）
- 添加"无限额度"切换开关
- 输入验证：>=0 整数

### 4. 客户管理页面 (`src/pages/Customers.tsx`)
- **信用额度显示**：null 显示"无限制"，0 显示"¥0"
- **剩余信用额度**：新增字段，实时计算
  - 公式：剩余额度 = 总额度 - 累计欠款 + 累计还款
  - 无限额度时显示"无限制"
  - 保留 2 位小数
- **视觉反馈**：
  - 绿色：剩余额度 > 20%
  - 黄色：剩余额度 < 20%
  - 红色：剩余额度 ≤ 0
- **调整按钮**：剩余额度旁增加快捷调整入口

### 5. 交易抽屉 (`src/components/TransactionDrawer.tsx`)
- 快速新建客户默认无限额度
- **超额控制（强管控）**：
  - 录入欠款时检查剩余额度
  - 新欠款 > 剩余额度 → 禁止提交 + 警告提示
  - 额度为 0 → 禁止录入欠款

### 6. 数据一致性
- 修改额度后自动刷新剩余额度
