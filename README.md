# 客户欠款助手

简单高效的客户欠款管理工具，帮助小店主轻松管理客户欠款和还款记录。

## 功能特性

- ✅ **客户管理** - 新增客户、查看客户列表、搜索客户
- ✅ **欠款录入** - 记录客户欠款，自动计算到期日
- ✅ **还款记录** - 记录客户还款，实时更新流水
- ✅ **流水展示** - 清晰展示所有交易记录
- ✅ **数据持久化** - 使用 IndexedDB 本地存储，刷新不丢失

## 技术栈

- **前端框架**: React 18 + TypeScript + Vite
- **样式方案**: Tailwind CSS
- **数据存储**: IndexedDB (Dexie.js)
- **状态管理**: Zustand
- **图标库**: Lucide React
- **日期处理**: date-fns

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用说明

1. **添加客户**: 点击底部导航"客户" → 右上角+号 → 填写客户信息
2. **记账**: 点击首页右下角+号 → 选择客户 → 输入金额 → 提交
3. **查看流水**: 首页展示所有最近流水记录
4. **删除记录**: 长按流水记录可删除
