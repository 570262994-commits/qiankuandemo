# 客户欠款助手 - 需求规格说明书

## 1. 项目概述

### 1.1 产品定义

客户欠款助手是一款面向小微企业主和个人经营者的欠款管理工具，用于记录和跟踪客户欠款、还款情况，帮助用户清晰掌握资金流动。

### 1.2 核心特性

- 客户信息管理（姓名、手机号、信用额度、账期）
- 欠款/还款记录
- 实时统计（总待收、总欠款、总还款、今日统计）
- 云端数据同步
- 多平台支持

## 3. 非功能需求

### 3.1 性能要求

- 页面加载时间 < 2秒
- 操作响应时间 < 500ms
- 支持离线缓存

### 3.2 安全要求

- 密码加密存储
- HTTPS 传输加密
- 行级数据隔离（RLS）

### 3.3 兼容性要求

- 支持 iOS Safari
- 支持 Android Chrome
- 支持桌面浏览器（Chrome、Firefox、Safari、Edge）

## 5. 数据模型

### 5.1 客户表 (customers)

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| id | SERIAL | 是 | 主键 |
| user_id | UUID | 是 | 用户ID（关联auth.users）|
| name | VARCHAR(20) | 是 | 客户姓名 |
| phone | VARCHAR(11) | 否 | 手机号 |
| credit_limit | DECIMAL(12,2) | 是 | 信用额度（0=不允许欠款，-1=无限）|
| payment_term | INTEGER | 是 | 固定账期（天）|
| created_at | TIMESTAMP | 是 | 创建时间 |

### 5.2 交易表 (transactions)

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| id | SERIAL | 是 | 主键 |
| user_id | UUID | 是 | 用户ID（关联auth.users）|
| customer_id | INTEGER | 是 | 客户ID（关联customers）|
| type | VARCHAR(10) | 是 | 类型（DEBT/PAYBACK）|
| amount | DECIMAL(12,2) | 是 | 金额 |
| occurred_at | TIMESTAMP | 是 | 发生日期 |
| due_date | TIMESTAMP | 是 | 到期日期 |
| note | TEXT | 否 | 备注 |
| created_at | TIMESTAMP | 是 | 创建时间 |
